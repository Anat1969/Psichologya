# מרחב פנימי

מקרה אחד. שלוש עדשות. מרחב אחד.

מעבדה לחשיבה ביוגרפית. כותבים מקרה, ושלוש עדשות קוראות אותו: ייעוץ ביוגרפי, פסיכולוגיית הצמצום ופסיכולוגיה בודהיסטית. כל עדשה מוצגת כגישה, כפתרון וכמרחב מחייה, עם פרומפט מוכן למידג'רני. הסינתזה מחברת את שלושתן לתמונה אחת ולמרחב אחד. את התמונות שמידג'רני מייצר גוררים, מדביקים או בוחרים, והן נשמרות לצד הכרטיס.

- אפיון: [docs/SPEC.md](docs/SPEC.md)
- כללי פיתוח ומבנה: [CLAUDE.md](CLAUDE.md)

## הרצה

```
npm install

npm run build && npm test
```
